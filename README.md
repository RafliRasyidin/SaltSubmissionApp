# Product Cart App 📱
A modern Android application demonstrating MVI (Model-View-Intent) architecture, Jetpack Compose, and Hilt dependency injection. This project features a clean, grayscale-driven design system and robust network handling via Retrofit.

🚀 Tech Stack
UI: Jetpack Compose for a declarative UI.

Architecture: MVI (Model-View-Intent) using StateFlow and Channels for side effects.

DI: Hilt for dependency injection.

Networking: Retrofit + OkHttp with logging interceptors.

Image Loading: Coil for optimized image rendering.

Formatting: Custom Java DecimalFormat for Indonesian Rupiah (Rp) currency.

🏁 Getting Started
Follow these steps to get the project up and running on your local machine.

1. Prerequisites
Android Studio Ladybug (or newer)

JDK 17 or 21

Android SDK 35 (for Android 15 features)

2. Installation
Clone the repository using HTTPS:

```Bash
git clone https://github.com/yourusername/your-repo-name.git
```
3. Build & Run
Open the project in Android Studio.

Wait for Gradle Sync to finish.
